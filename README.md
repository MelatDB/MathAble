# MathAble — math practice web app for blind & visually impaired students

Accessibility-first mathematics practice. The API always returns a spoken
sentence, a MathML fragment, and structured steps for every problem, and the
solver engine computes real answers with **SymPy** (never a hard-coded lookup).
The frontend is a keyboard-first React SPA with a skip link, live-region
announcements, focus management, voice navigation, and text-to-speech.

MathAble supports two account roles:

- **Students** — solve problems, practise topics, review progress, and read
  their solution history.
- **Teachers** — view class progress and create and manage assignments.

## Features

- **Symbolic math solver** — expressions are parsed and solved with SymPy;
  answers, spoken narration, and MathML are generated from the real result.
- **Practice sessions** — generated by topic and difficulty, with answer
  checking, feedback, and attempt tracking.
- **Progress dashboard** — overall accuracy and per-topic progress with
  "Strong / Developing / Getting started" bands.
- **Three navigation modes** — Voice, Keyboard, or Voice + Keyboard, chosen on
  first run and changeable in Settings at any time.
- **Screen-reader-first UI** — skip link, ARIA live regions, focus management,
  and plain-language error messages.
- **Text-to-speech** — page guides, questions, explanations, and solutions can
  be read aloud; rate and voice are configurable.
- **Voice dictation** — speak mathematical expressions into the solver and
  practice answer fields.
- **Accessibility settings** — text size, contrast theme, TTS rate/voice, and
  voice input are persisted per user.


## Backend

Requires Python 3.11+. From `backend/`:

```bash
python -m venv ../venv
source ../venv/bin/activate          # Windows: ..\venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                  # set DATABASE_URL / SECRET_KEY
uvicorn app.main:app --reload
```

API docs: http://127.0.0.1:8000/docs · Health check: `/api/health`.

### Endpoints (all under `/api`)

| Method | Path                                   | Purpose                              |
|--------|----------------------------------------|--------------------------------------|
| POST   | /auth/register                         | Create account, return JWT           |
| POST   | /auth/login                            | Log in, return JWT                   |
| POST   | /auth/logout                           | Invalidate client token              |
| GET    | /users/me                              | Current profile                      |
| POST   | /solve                                 | Interpret + solve an expression      |
| GET    | /problems/history                      | Recent solved problems               |
| POST   | /practice/generate                     | Generate a practice session          |
| POST   | /practice/submit                       | Check an answer, record attempt      |
| GET    | /progress                              | Per-topic accuracy + recent activity |
| GET    | /accessibility/settings                | Saved accessibility preferences      |
| PUT    | /accessibility/settings                | Update accessibility preferences     |
| GET    | /health                                | Liveness probe                       |
| GET    | /teacher/students                      | Teacher's student list               |
| GET    | /teacher/students/{id}/progress        | A student's progress summary         |
| GET    | /teacher/students/{id}/solutions       | A student's solution history         |
| GET    | /teacher/assignments                   | List assignments                     |
| POST   | /teacher/assignments                   | Create an assignment                 |
| PUT    | /teacher/assignments/{id}              | Update an assignment                 |
| DELETE | /teacher/assignments/{id}              | Delete an assignment                 |
| GET    | /teacher/assignments/{id}/results      | Assignment results for the class     |

All solving is done symbolically with SymPy — the answer, spoken sentence and
MathML are computed from the actual solution, never from a lookup table.

## Frontend

Requires Node.js 18+. From `frontend/`:

```bash
npm install
npm run dev          # http://localhost:5173
```

The dev server proxies `/api`, `/docs`, and `/openapi.json` to
`http://127.0.0.1:8000` by default. Override with the `MATHABLE_API_URL`
environment variable:

```bash
MATHABLE_API_URL=http://127.0.0.1:9000 npm run dev
```

Production build:

```bash
npm run build        # outputs to frontend/dist
npm run preview
```

The landing-page hero uses an optional background image at
`frontend/public/hero-bg.jpg`. If the file is absent the hero still renders,
just without the image overlay.

## Keyboard shortcuts

Global shortcuts work everywhere and do not require a modifier other than Alt.

| Shortcut | Action                                        |
|----------|-----------------------------------------------|
| Alt+1    | Go to the Dashboard                           |
| Alt+A    | Open the Math Input Workspace and focus input |
| Alt+S    | Submit a practice answer or solve the form    |
| Alt+P    | Open Practice                                 |
| Alt+H    | Open Help                                     |
| Tab / Shift+Tab | Move forward/backward between controls |
| Enter    | Activate the focused control / submit         |

## Voice navigation

Voice commands are matched from speech recognition transcripts and cover page
navigation, solving, practice, reading, settings, and topic/difficulty
selection. A few examples:

- "Solver", "Practice", "Progress", "Settings", "Help", "Home", "Back"
- "Solve x squared plus five"
- "Answer 42", "Submit", "Next question"
- "Read question", "Read explanation", "Read solution", "Stop reading"
- "Voice navigation", "Keyboard navigation", "Voice and keyboard"

Math dictation is kept separate from navigation so an expression such as
"five x plus three" is treated as math, not as a command.

## Accessibility

- Every endpoint returns `_spoken` and `_mathml` variants of the math so a
  screen reader (and the optional TTS) can read it aloud correctly.
- The frontend provides a skip link, keyboard-only navigation, focus
  management, and live-region announcements (WCAG 2.1 AA intent).
- Page guides are spoken automatically **only** in Voice or Voice + Keyboard
  mode. In Keyboard-only mode pages stay silent, so TTS never talks over a
  screen reader unless the user asks for it; individual "Read aloud" buttons
  still work everywhere.
- Switching to Keyboard-only mode immediately stops any in-progress speech.
- Text size, contrast, TTS rate and voice-input toggles are persisted per user
  under `/api/accessibility/settings`.
